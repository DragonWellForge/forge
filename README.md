# Dragon Well Forge

**We make the abstract into reality.**

Landing page and web presence for Dragon Well Forge — a Portland, OR based maker studio specializing in personalized pet care pages and 3D printed products.

## Products
- Pet Care Page + QR Display — because their care is too important to explain twice.
- 3D Printed Goods — precision made, community focused.

## Stack
- HTML / CSS / Vanilla JS
- GitHub Pages (free hosting)
- No frameworks. No dependencies. Just the forge.
